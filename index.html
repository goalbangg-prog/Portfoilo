01 · NGMS 매뉴얼 안내 도구

NGMS
Manual Copilot

NGMS 사용법을 질문하면
매뉴얼에서 답을 찾아줍니다.

NGMS 매뉴얼에서 필요한 내용을 쉽게 찾을 수 있도록 만든 도구입니다. 공식 PDF 5종을 질문과 답변 형태로 정리하고 검수했습니다. 답변에는 메뉴 위치와 처리 절차, 참고한 문서의 페이지가 함께 나오도록 했습니다.

제작 과정
PDF 내용을 질문·답변으로 정리한 뒤 검수하고, Markdown 파일로 만들어 Google Opal에 연결했습니다.
구현
메뉴 경로, 처리 방법, 주의사항과 출처를 안내합니다. 자료에 없는 내용은 확인할 수 없다고 답하도록 설정했습니다.

02 · 배출권 이행비용 비교 도구

K-ETSCompliance &
Cost Optimizer

배출권 구매와 감축 방안별로
예상 비용을 비교합니다.

배출량과 할당량, 배출권 가격을 입력하면 대응 방안별 비용을 비교하도록 만들었습니다. n8n에서 규정 확인과 비용 계산을 처리하고, AI가 결과를 설명한 보고서를 Google Docs에 작성합니다.

계산 방식
규정과 가격 등의 가정을 별도로 관리하고, Code Node에서 계산하도록 구성했습니다. AI에는 계산 결과를 설명하는 역할만 맡겼습니다.
결과
감축수단과 배출권 구매 조합을 계산하고, 시나리오별 비용을 비교한 보고서를 자동으로 작성합니다.

가상 기업 데이터로 시험한 프로토타입입니다. 실제 업무에 적용하려면 최신 규정과 계산 조건을 추가로 검토해야 합니다.

03 · 기사 작성 시스템 · 팀 프로젝트

PRESS-CMS

기사 작성과 검토를 위한
콘텐츠 관리 시스템입니다.

취재 자료와 사진을 정리하고, 기사를 작성·검토할 수 있는 시스템을 팀 프로젝트로 만들었습니다. 기자에게 받은 의견을 반영해 편집 화면을 수정하고, 초안 작성과 검수를 돕는 AI 기능을 추가했습니다.

나의 역할
팀장을 맡아 기자의 의견을 정리하고 편집 화면의 개선 방향을 제안했습니다. GitHub 협업 환경 구성, Render 배포, 작업일지와 발표자료 작성·통합도 담당했습니다.
주요 기능
기사 편집, 사진·자료 관리, 문장별 피드백, 역할별 검토·출고, AI 초안 작성 및 검수 보조
